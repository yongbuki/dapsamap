# 답사 지도 3D

건축물·장소·관찰 기록을 지도에 남기고, 대지와 매스를 분석하는 웹 앱입니다.
`index.html` 하나로 배포하며, GitHub Pages에서도 실행할 수 있습니다.

## 로컬 실행

프로젝트 폴더에서 아래 명령을 실행하고 `http://localhost:8000`을 여세요.

```sh
python -m http.server 8000
```

지도·검색·지형 자료에는 인터넷 연결이 필요합니다. 브이월드·카카오·건축물대장
연동 설정은 앱의 설정 메뉴에 있습니다.

기록·대지·사진은 접속한 사이트 주소별로 브라우저에 저장됩니다.
GitHub Pages의 기록은 localhost에서 자동으로 보이지 않습니다.
주소나 기기를 바꿀 때는 설정에서 사진을 포함해 JSON을 내보내고 가져오세요.

## 안정성 개선

- 백업의 누락·빈 좌표를 0으로 바꾸지 않고, 위도·경도 범위를 검증합니다.
- 같은 백업에 같은 ID가 여러 번 있어도 최신 기록과 대지를 유지합니다.
- 기록·대지·사진을 하나의 IndexedDB 트랜잭션으로 저장합니다.
  저장이 실패하면 해당 가져오기의 변경 사항을 모두 취소합니다.
  건물 높이 보정은 이 저장이 성공한 뒤 기존 localStorage 방식으로 적용합니다.
- 일부 대지 항목이 null이어도 가져오기를 계속하고, 중복 실행을 막습니다.
- 실패 메시지를 표시하고 재시도할 수 있도록 가져오기 상태를 해제합니다.

## 백업 회귀 테스트

Node.js와 Playwright가 필요합니다. 기존 설치가 없다면:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/backup.cjs
```

시스템의 `/usr/bin/chromium`이 있으면 사용하며, `CHROMIUM_PATH`로 실행 파일을
지정할 수도 있습니다. 없으면 Playwright가 설치한 Chromium을 사용합니다.

테스트는 임시 로컬 서버와 격리된 브라우저를 사용합니다. 외부 지도 요청을 차단해
좌표 검증, 중복 병합, 사진 복원, 저장 실패와 비동기 취소 시 전체 롤백,
실패 후 재시도, 새로고침 후 보존, 잘못된 파일 처리를 확인합니다.
지도 표시 및 외부 API 연동은 이 테스트 범위에 포함하지 않습니다.

## 모바일 화면

휴대폰에서는 대지 분석·장소 검색·기록 목록·설정 메뉴를 화면 아래에 표시합니다.
오른쪽의 지도 도구는 `지도 도구` 버튼으로 펼칠 수 있습니다. 작성 중인 기록은
저장하거나 취소한 뒤 다른 메뉴로 이동할 수 있습니다.

입력창은 16px, 주요 터치 버튼은 최소 44px로 표시하고 화면 확대를 허용합니다.
지원 브라우저에서는 visualViewport로 키보드 위의 실제 화면 높이를 읽어
입력 패널과 저장 버튼의 위치를 조절합니다. 실제 키보드 동작은 기기와 브라우저에
따라 차이가 있으므로 iOS Safari와 Android Chrome에서도 확인하는 것이 좋습니다.

```sh
node tests/mobile.cjs
```

320×568, 390×844, 844×390, 1280×800 화면에서 메뉴 접근, 도구 스크롤,
패널의 가로 넘침, 입력·저장 버튼과 키보드 높이 변경 모의를 검증합니다.
`SCREENSHOT_DIR` 환경 변수를 지정하면 화면 캡처도 저장합니다.
