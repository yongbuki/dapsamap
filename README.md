# 답사 지도 3D

건축물·장소·관찰 기록을 지도에 남기고, 대지와 매스를 분석하는 웹 앱입니다.
`index.html` 하나로 배포하며, GitHub Pages에서도 실행할 수 있습니다.

## 로컬 실행

프로젝트 폴더에서 아래 명령을 실행하고 `http://localhost:8000`을 여세요.

```sh
python -m http.server 8000
```

지도·검색·지형 자료에는 인터넷 연결이 필요합니다. 브이월드·카카오·건축물대장
연동 설정은 앱의 설정 메뉴에 있습니다.

기록·대지·사진은 접속한 사이트 주소별로 브라우저에 저장됩니다.
GitHub Pages의 기록은 localhost에서 자동으로 보이지 않습니다.
주소나 기기를 바꿀 때는 설정에서 사진을 포함해 JSON을 내보내고 가져오세요.

## 안정성 개선

- 백업의 누락·빈 좌표를 0으로 바꾸지 않고, 위도·경도 범위를 검증합니다.
- 같은 백업에 같은 ID가 여러 번 있어도 최신 기록과 대지를 유지합니다.
- 기록·대지·사진을 하나의 IndexedDB 트랜잭션으로 저장합니다.
  저장이 실패하면 해당 가져오기의 변경 사항을 모두 취소합니다.
  건물 높이 보정은 이 저장이 성공한 뒤 기존 localStorage 방식으로 적용합니다.
- 일부 대지 항목이 null이어도 가져오기를 계속하고, 중복 실행을 막습니다.
- 실패 메시지를 표시하고 재시도할 수 있도록 가져오기 상태를 해제합니다.

## 백업 회귀 테스트

Node.js와 Playwright가 필요합니다. 기존 설치가 없다면:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/backup.cjs
```

시스템의 `/usr/bin/chromium`이 있으면 사용하며, `CHROMIUM_PATH`로 실행 파일을
지정할 수도 있습니다. 없으면 Playwright가 설치한 Chromium을 사용합니다.

테스트는 임시 로컬 서버와 격리된 브라우저를 사용합니다. 외부 지도 요청을 차단해
좌표 검증, 중복 병합, 사진 복원, 저장 실패와 비동기 취소 시 전체 롤백,
실패 후 재시도, 새로고침 후 보존, 잘못된 파일 처리를 확인합니다.
지도 표시 및 외부 API 연동은 이 테스트 범위에 포함하지 않습니다.

## 모바일 화면

휴대폰에서는 대지 분석·장소 검색·기록 목록·설정 메뉴를 화면 아래에 표시합니다.
오른쪽의 지도 도구는 `지도 도구` 버튼으로 펼칠 수 있습니다. 작성 중인 기록은
저장하거나 취소한 뒤 다른 메뉴로 이동할 수 있습니다.

입력창은 16px, 주요 터치 버튼은 최소 44px로 표시하고 화면 확대를 허용합니다.
지원 브라우저에서는 visualViewport로 키보드 위의 실제 화면 높이를 읽어
입력 패널과 저장 버튼의 위치를 조절합니다. 실제 키보드 동작은 기기와 브라우저에
따라 차이가 있으므로 iOS Safari와 Android Chrome에서도 확인하는 것이 좋습니다.

```sh
node tests/mobile.cjs
```

320×568, 390×844, 844×390, 1280×800 화면에서 메뉴 접근, 도구 스크롤,
패널의 가로 넘침, 입력·저장 버튼과 키보드 높이 변경 모의를 검증합니다.
`SCREENSHOT_DIR` 환경 변수를 지정하면 화면 캡처도 저장합니다.

## 도보권·경로 분석

대지 분석 → `도보 5·10·15분 분석`에서 사용할 수 있습니다. 선택한 대지가 있으면
대지 중심, 없으면 현재 지도 중심이 출발점입니다. 결과에 출발점 좌표와 분석 조건을
표시하고, 지도에서 도보 시간에 따라 도로 색상을 다르게 표시합니다.

- 긴 도로의 중간에서도 가까운 길 진입점부터 경로를 계산합니다.
- `계단을 제외하고 분석`을 켜면 등록된 계단 구간을 도로망에서 제거합니다.
  보행 속도와 별개로 선택하며, 속도·계단 조건을 바꾸면 같은 출발점에서 재계산합니다.
- 시설별 `길 보기` 버튼으로 가장 가까운 시설까지 경로와 목적지를 표시합니다.
  모바일에서는 지도 영역을 넓히고 `결과 넓게` 버튼으로 돌아올 수 있습니다.
- 직선 거리 원은 별도 옵션입니다. 5·10·15분별 시설 수와 추정 도보권 면적을
  함께 비교할 수 있으며, SVG에는 선택한 경로와 계단 조건도 포함합니다.
- 지형 자료가 없거나 일부 누락되면 결과에 표시합니다. 계단 제외는 휠체어·유모차의
  실제 통행 가능 여부를 보장하지 않습니다. 경사·턱·출입구는 현장 확인이 필요합니다.
- 다른 대지·프로젝트로 바꾸거나 대지 경계를 수정하면 이전 도보 결과를 지웁니다.
  실행 중인 분석은 `지우기·취소`로 중단할 수 있습니다.

```sh
node tests/walking.cjs
```

거리가 알려진 가상 도로망으로 도로 중간 출발, 연결 거리, 계단 우회,
끊어진 평행 도로, 오르막, 누락 지형, 시간별 도로 표시, SVG, 모바일 패널과
분석 취소를 검증합니다. 실제 OpenStreetMap 자료와 외부 API의 완전성은
이 테스트로 검증하지 않습니다.

## 건축 설계 과제

대지를 선택하면 `과제 노트 · 프로그램 · 설계안 비교` 카드가 표시됩니다.
과제 제목, 설계 의도, 현장 관찰, 크리틱 질문을 기록하고 실별 순면적과 개수를
입력하세요. 순면적 합계를 계획 전용률로 나눈 목표 연면적을 현재 매스와 비교합니다.
입력 내용은 필드 수정을 마치면 해당 대지에 저장됩니다.

`현재 설계안 지표 기록`은 당시의 면적·높이·건폐율·용적률을 최대 12개까지
보존합니다. 형상을 복원하는 기능은 아니며, 전체 작업은 설정에서 JSON으로
백업할 수 있습니다. 과제 노트와 프로그램·비교 지표도 백업에 포함됩니다.

`과제 분석 보고서 · A3 / PDF`는 외부 연결 없이 열 수 있는 HTML을 다운로드합니다.
파일을 열고 인쇄에서 PDF를 선택하세요. 대지와 직접 그린 매스의 벡터 평면,
북쪽 표시와 스케일바, 현재 지표, 노트, 프로그램표와 비교표를 포함합니다.
가져온 모델 형상은 평면 도식에 표시하지 않으며, 내용이 많으면 여러 장으로 이어집니다.
면적 지표는 설계 스터디용이며 법정 면적 산정이나 측량 성과를 대체하지 않습니다.

```sh
node tests/course.cjs
```

프로그램 합계, 설계안 지표 보존, 백업 호환, 모바일 입력, 재접속 후 보존,
사용자 텍스트 처리와 A3 PDF 생성을 검증합니다.

## 브라우저 도면·매스 편집기

대지 분석 → 대지 선택 → 내 도면·모델 → `도면·매스 편집기 열기`에서 실행합니다.
별도 프로그램 없이 사각형 평면을 두 모서리로 그리거나 가로·세로 치수로 추가하고,
선택·끌어 이동·수치 이동·회전·비율 변경·복제·삭제·되돌리기를 사용할 수 있습니다.
기존 매스도 함께 편집하며, 선택 도형의 수치는 `선택 도형에 적용`으로 반영합니다.

층수·층고·띄움 높이를 지정하고 `3D 보기`에서 회전·확대해 확인하세요.
3D 라이브러리 연결에 실패해도 평면 편집과 저장은 계속 가능합니다.
`대지에 저장`하면 기존 매스 목록이 편집 결과로 갱신되고 면적·그림자·단면 등 기존
매스 분석과 연결됩니다. JSON 전체 백업에도 포함되며, 저장은 현재 브라우저 기준입니다.

DXF는 대지 중심을 원점으로 한 로컬 미터 평면이고, OBJ는 같은 원점의 미터 모델이며
Y축이 위입니다. 재배치 시 원점·축을 확인하세요. 편집기는 단순 매스 설계용 첫 버전으로,
벽·문·창의 BIM 관계, IFC, 렌더 재질·자유곡면 편집은 포함하지 않습니다.

```sh
node tests/editor.cjs
```

회전 도형, 오목 다각형의 삼각분할, DXF 단위, OBJ 높이와 브라우저 편집·되돌리기·
파일 내보내기·저장·재접속 및 3D 미리보기를 확인합니다.
